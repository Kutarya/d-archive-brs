# Muvv geliştirme notları

Bu depo cihaz protokol notları, tasarım ve çalışma durumunu tutar. Uygulama kodu kardeş `Muvv` deposundadır.

2026-10-11 sürüm 0.2 güncellemesi güvenli IPC, USB işlem sonuçları, süreli kapanış, Vitray efektleri, bağımsız RGB renkleri, aktarılabilir profiller ve masaüstü arayüzünü kapsar. [Aktif çalışma](memory-bank/activeContext.md), [ilerleme](memory-bank/progress.md), [mimari kararlar](memory-bank/systemPatterns.md) ve [ortam kurulumu](python_environment_setup.md) güncel kaynakla uyumludur.

`proje.md` mevcut tasarımı, `development environment.md` kaynak ve test düzenini açıklar. Windows cihaz servisi, evdev, makro ve sistem tepsisi işleri henüz uygulanmadı. Truemove tablosu model protokol referansıdır; fiziksel ölçüm kaydı değildir.

Linux ve gerçek fare kabulü uygulama deposundaki `docs/HARDWARE-ACCEPTANCE.md` üzerinden yapılır. Yerel demo veya sahte HID testi fiziksel doğrulama yerine geçmez.
